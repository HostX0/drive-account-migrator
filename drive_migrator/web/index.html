A one-time Google setup

Use your own Google project. No paid API key, AI service or hosting.

  1. Create a Google Cloud project

    Open Google Cloud Console and create a project. Enable Google Drive API and Google Docs API. This setup does not require enabling billing or starting a trial.

    Open Google Cloud Console ↗

  2. Set up the consent screen

    In Google Auth Platform, choose External and Testing. Add both email addresses under Audience → Test users.

  3. Download the connection file

    Go to Clients → Create client → Desktop app. Download JSON. Choose that file on the Connect accounts page. Each user creates their own client; never post it publicly.

  4. Prepare your folders

    Share the source folder with the new account as Viewer in Google Drive so it can copy the files. In the new account, create a destination folder with the exact same name. Paste both folder links.

  5. Connect, preview, copy

    Connect the old and new accounts in your browser. Check each email on Google’s consent page. Create the controller once, build a preview, then copy. Optional cleanup has a separate authorization and reviewed plan.
